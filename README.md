# Trabajo-de-Grado-Modelos-bayesianos-para-la-prediccion-de-los-resultados-de-las-pruebas-Saber-11
Almacena los resultados de las predicciones realizadas con modelos Dirichlet y Dirichlet Generalizado para los colegios con mas de 30 estudiantes que presentaron la prueba en los años 2022-2025
Incialmente almacena los resultados de las 10 capitales mas pobladas del pais. Conforme avance el proyecto, se subiran los datos correspondientes al resto del pais
